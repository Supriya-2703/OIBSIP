# OASIS INFOBYTE — Data Analytics Internship

## Level 1 — Task 1: EDA on Retail Sales Data

### 📌 Project Overview

This project was completed as part of the **OASIS INFOBYTE Data Analytics Internship**.

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on a retail sales dataset to identify sales trends, customer behaviour patterns, product-category performance, and relationships between numerical variables.

The analysis uses Python-based data analysis and visualization techniques to transform raw transaction data into meaningful business insights.

---

## 🎯 Objectives

The main objectives of this project are to:

- Understand the structure and quality of the retail sales dataset.
- Perform data cleaning and preprocessing.
- Calculate descriptive statistics for numerical variables.
- Analyse monthly and quarterly sales trends.
- Study customer demographics such as age and gender.
- Analyse product-category sales and revenue.
- Examine relationships between numerical variables using correlation analysis.
- Identify additional customer behaviour insights.
- Develop actionable business recommendations based on the analysis.

## 📊 Dataset Description

The dataset contains **1,000 retail transactions** and **9 columns**.

| Column           | Description                            |
| ---------------- | -------------------------------------- |
| Transaction ID   | Unique identifier for each transaction |
| Date             | Date on which the transaction occurred |
| Customer ID      | Unique customer identifier             |
| Gender           | Customer gender                        |
| Age              | Customer age                           |
| Product Category | Category of the purchased product      |
| Quantity         | Number of units purchased              |
| Price per Unit   | Price of one unit                      |
| Total Amount     | Total transaction amount               |

The `Date` column was converted from text format to the `datetime` data type to enable time-series analysis.

---

## 🔍 Analysis Performed

### 1. Initial Data Inspection

The dataset was inspected to determine:

- Number of rows and columns
- Column names
- Data types
- Dataset structure
- Missing values
- Duplicate records

---

### 2. Data Cleaning

The following preprocessing steps were performed:

- Checked for missing values.
- Checked for duplicate records.
- Converted the `Date` column to `datetime`.
- Created additional time-based features such as month and quarter.
- Created customer age groups for demographic analysis.

---

### 3. Descriptive Statistics

Descriptive statistics were calculated for numerical columns using:

- Mean
- Median
- Mode
- Standard deviation

These statistics help understand the central tendency and variability of the numerical variables.

---

### 4. Monthly Sales Analysis

Monthly total sales were calculated and visualized using a line chart.

This analysis helps identify:

- High-sales periods
- Low-sales periods
- Possible seasonal patterns
- Changes in revenue over time

---

### 5. Quarterly Sales Analysis

Sales were grouped by quarter and visualized using a line chart.

Quarterly analysis provides a broader view of sales performance and can support business planning and performance monitoring.

---

### 6. Customer Demographic Analysis

Customer demographics were analysed using:

#### Age Groups

Customers were divided into meaningful age groups to understand which segments account for more transactions.

#### Gender

The distribution of transactions across gender categories was visualized using a bar chart.

---

### 7. Product Category Analysis

The dataset contains a **Product Category** field rather than individual product names.

Therefore, product-category performance was analysed using:

- Quantity sold by category
- Revenue generated by category

Bar charts were used to compare category performance.

> **Dataset Limitation:** Individual top-10 product analysis could not be performed because the original dataset does not contain a product-name column. No product-level information was artificially created.

---

### 8. Correlation Analysis

A correlation matrix was calculated for numerical variables and visualized using a heatmap.

The analysis helps identify relationships between variables such as:

- Age
- Quantity
- Price per Unit
- Total Amount

Correlation values closer to `+1` indicate a strong positive linear relationship, while values closer to `-1` indicate a strong negative relationship.

---

### 9. Additional Analysis

An additional analysis was performed to compare **average transaction value across customer age groups**.

This provides a different perspective from simply counting the number of customers or transactions.

It helps distinguish between:

- High-volume customer segments
- Higher-value customer segments

## 💡 Key Business Insights

The analysis provides several business-oriented insights:

1. **Sales trends** can help identify periods of higher and lower revenue and support inventory and staffing decisions.

2. **Customer demographics** can help businesses understand their primary customer groups and develop targeted marketing strategies.

3. **Product-category performance** helps identify categories that contribute strongly to sales volume and revenue.

4. **Average transaction value by age group** provides additional information about the value of different customer segments.

5. **Quantity and revenue should be analysed together**, because a category with high sales volume does not necessarily generate the highest revenue.

---

## 🚀 Business Recommendations

Based on the analysis, the following recommendations can be considered:

### 1. Focus on high-performing product categories

Categories generating strong sales volume and revenue should receive appropriate inventory support and targeted promotional campaigns.

### 2. Use customer demographics for targeted marketing

Age-group and gender analysis can help businesses develop more relevant marketing campaigns and product recommendations.

### 3. Target higher-value customer segments

Customer segments with higher average transaction values can be targeted with premium products, bundles, loyalty programs, and personalized offers.

### 4. Plan inventory using sales trends

Monthly and quarterly sales patterns can be used to anticipate changes in demand and improve inventory planning.

### 5. Monitor multiple KPIs

Businesses should evaluate revenue, quantity sold, transaction count, and average transaction value together instead of relying on a single metric.
